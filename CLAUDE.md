# Mantra Wheel

A paced japa (mantra repetition) companion on a 108-bead mala. It's a single `index.html` with no build step. See `README.md` for features.

## Rules
- Keep it one self-contained file. The session log stays in browser localStorage, with no accounts.
- Every mantra carries its native script, transliteration, plain meaning, lineage and a source note. Keep that sourcing discipline, and present meanings as respectful summaries, not doctrine.
- Keep it separate from Rosary Vigil. They share patterns (voice scoring, pacing), not code or content.
- Chime and sounds are synthesized in the browser. No audio files.
